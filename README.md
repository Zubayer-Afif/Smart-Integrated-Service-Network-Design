The project focuses on designing a complete enterprise network for a Smart Integrated Service Network (SISN) consisting of 
six operational units: Head Office (HO), Training Center (TC), Software Lab (SL), Support Division (SD), Remote Branch (RB), and Archive Unit (AU). 
Each unit is equipped with routers, switches, PCs, printers, and email servers, while HO hosts the central DNS and web services.

The network uses VLSM subnetting based on the assigned group ID and implements both static and dynamic routing. 
Different static routing techniques, including next-hop, exit-interface, recursive, floating, and default static routes, are combined with RIPv2 to provide efficient and reliable communication. 
DHCP is configured using both routers and dedicated servers, while DNS, web, and email services are configured to demonstrate application-level connectivity.
The design also provides redundancy and fault tolerance, allowing traffic to automatically reroute when primary links fail. 
The project demonstrates complete network connectivity, dynamic IP addressing, server functionality, routing integration, and backup paths between critical network segments.


*** To run and test the completed network, open the .pkt file using Cisco Packet Tracer. ***
